🚀 **Featured Projects**

💊 **Smart Medicine Reminder Box**

Arduino • RTC • LCD • EEPROM • Buzzer • LEDs

Developed an Arduino-based smart medicine reminder system to help users take medications on time. The system uses an RTC module, LCD, buzzer, LEDs, buttons, and EEPROM to manage and store medication schedules. It provides both visual and audio alerts at the scheduled time. The project focuses on improving medication adherence through a low-cost embedded solution.

📊 **UIDAI Aadhaar Analytics Challenge**

Python • Pandas • NumPy • Power BI • Data Analytics

Analyzed Aadhaar enrolment and biometric update datasets to identify regional trends, operational challenges, and service-demand patterns. Used Python, Pandas, NumPy, and Power BI for data cleaning, analysis, visualization, and dashboard development. AI • Document Management • NLP • Multilingual Processing • SIH 2025

Developed an AI-powered document management concept for Kochi Metro Rail Limited to improve document organization, accessibility, and decision-making. The solution includes document classification, AI-powered summarization, multilingual document processing, intelligent search, and document traceability. 🚆 **Smart Train Speed Control System**

Arduino Uno • L293D • DC Motors • Obstacle Detection

Developed an Arduino-based railway safety system capable of detecting obstacles on railway tracks and automatically controlling train speed. The system uses Arduino Uno, an L293D motor driver, DC motors, and an obstacle detection mechanism. When an obstacle is detected, the system reduces the motor speed to help prevent potential collisions. The project demonstrates the application of embedded systems and automation to railway safety.
